# 샘플 평가 접근 확인과 UX 참고 범위

## 확인한 사실

- 사용자가 지정한 참고 URL: <https://school.programmers.co.kr/tryouts/219121/challenges/quizzes/57305>
- 클라우드 환경에서 일반적인 HTTPS 요청으로 접근을 시도했으나 프록시의 `CONNECT 403` 응답으로 차단되었습니다. 확인된 제한은 현재 실행 환경의 아웃바운드 도메인 정책이며, 이를 해당 사이트의 로그인 요구나 실제 샘플 내용에 관한 증거로 해석하지 않습니다.
- 샘플 시험의 실제 화면·문항·선택지·시간 제한·제출 결과를 열람하지 못했습니다. PC·모바일 반응형 동작 역시 직접 확인하지 못했습니다.
- 로그인·접근 제어를 우회하거나 비공개 API·인증 토큰을 사용하지 않았습니다. 원문 문항·선택지·소스코드·브랜드 디자인을 가져오지 않았습니다.

## 이번 구현에 적용한 일반적인 평가 UX

| 분석 항목          | 원본에서 확인 여부 | 자체 구현 원칙                                               |
| ------------------ | ------------------ | ------------------------------------------------------------ |
| 문제 본문과 선택지 | 미확인             | 영역·난이도·문제 본문과 큰 단일선택 답안 영역                |
| 문항 이동          | 미확인             | 이전·다음, 문제 번호 직접 이동, 현재 위치 표시               |
| 미응답             | 미확인             | 문항 상태·미응답 개수·제출 전 확인                           |
| 시간·진행률        | 미확인             | 학습 무제한, 모의평가 자체 설정 25분과 제한 해제 옵션        |
| 답안 보존          | 미확인             | 브라우저에 세션·고정 출제 배열·답안·마감 시각 저장           |
| 제출·결과          | 미확인             | 확인 다이얼로그, 중복 제출 방지, 정오·미응답·해설            |
| 모바일             | 미확인             | 접을 수 있는 번호판, 큰 터치 영역, 반응형 레이아웃           |
| 접근성             | 미확인             | 키보드 입력, 명시적 레이블, 포커스 표시, 색상 외 상태 텍스트 |

이 패턴은 사용자의 요구사항과 일반적인 학습·평가 UX를 바탕으로 설계했습니다. 원본 서비스에서 관찰한 기능이라고 주장하지 않습니다. 자체 모의평가 20문항·25분은 원본 시험 규칙을 재현한 값이 아닙니다.

## 문제 데이터의 출처

초기 64문항은 AI 지식·활용 판단을 평가하도록 독창적으로 작성했으며 `provenance: "original"`로 표시합니다. 프로그래머스 샘플 문항의 재현이나 전재가 아닙니다. 출처 유형은 저작권 허가 자체를 증명하지 않으므로 이후 외부 문항을 추가할 때에는 허가 범위와 근거를 별도로 확인해야 합니다.

사용자가 권한을 가진 JSON·JSONL·Markdown 문항을 제공하면 [문항 작성 안내](QUESTION_AUTHORING.md)의 형식 검증과 내용 검토를 거쳐 가져올 수 있습니다. 정확성이나 공개 권한을 확인할 수 없는 문항은 `status: "review"`로 두고 정식 출제에서 제외합니다.
